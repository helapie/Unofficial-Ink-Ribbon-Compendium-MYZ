Here you can find the unofficial game (Mutant Year Zero format) to run Dead on Arrival for the Ink Ribbon system made by Old Oak Games, 
they have a backer kit, at: https://www.backerkit.com/c/projects/old-oak-games/ink-ribbon-a-survival-horror-tabletop-rpg/pre-launch

I am not a developer so I used the Mutant Year Zero to makeshift the character sheets etc.

So, I believe this should work,
In your FoundryVTT local storage, where the worlds are saved, you should save this, and unzip the other folders.
Then you should be able to open FoundryVTT and use it.
I will test this to double-check.

If you already have a world, and the maps, handouts etc. and you ONLY  want the compendium, than I think you just need to download the 'packs' zip, 
and place the individual folders inside of it, into your Mutant Year Zero world packs folder that should already exist.

I am happy to do this, if it works, for other systems, I chose Mutant Year Zero because it would let me alter all the skills. 
The only thing I couldn't change is the attribute 'Empathy' to be renamed to 'Heart'.

Most rolls are expected to be manual rather than automatic, the information is still there.
There are the traditional character sheets in Actors, but also Ink Ribbon sheets made in Journal.

FoundryVTT 14.

I use a lot of modules, and I recommend:
Dice So Nice,
Dice Tray and edit to have only the d6 as an option.
Blood Splatters,
Patrol, which works nicely to have the wandering enemies move about.
Boss Health Bar, for the 'Health' of Nemesis enemy.
